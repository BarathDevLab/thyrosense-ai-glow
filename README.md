# ThyroSense AI

An AI-powered thyroid health application with image analysis, health tracking, and personalized insights.

## Tech Stack
- **Framework:** Next.js, TypeScript
- **AI:** Gemini Flash image analysis
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

## Features
- AI-powered thyroid health image analysis
- Personalized health insights and tracking
- Responsive UI with modern design
- RESTful API backend

## Getting Started
```bash
git clone https://github.com/BarathDevLab/thyrosense-ai-glow
cd thyrosense-ai-glow
npm install
npm run dev
```
